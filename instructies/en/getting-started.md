# Getting Started with ICUdata

Welcome to the ICUdata GitHub. Read these guides in this order:

1. [Gaining access](01-access.md): MyDRE account and research request.
2. [Start the VM and log in](02-start-and-log-in.md): start the Linux VM and log in.
3. [Working environment](03-working-environment.md): VSCode, the database, Python, R and applications on the Linux VM.
4. [Network and GitHub](04-network-and-github.md): network restrictions, GitHub access, and requesting applications or internet access.
5. [Data and code](05-data-and-code.md): uploading data, working with code, and getting results out of MyDRE.
6. [Windows VM and SSH](06-windows-vm-and-ssh.md): only if you need the Windows VM.

For the database itself, see the [Database Guide](database-guide.md) and the [OMOP explanation](omop-explanation.md).
